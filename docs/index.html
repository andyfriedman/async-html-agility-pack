Async Html Agility Pack

An async-first HTML parser for .NET that builds a read/write DOM you can query with XPath or LINQ, even when the markup is malformed.

Html Agility Pack (HAP) reads HTML the way browsers do. It accepts unclosed tags, unquoted attributes and stray end tags, and gives you a tree of HtmlNode objects. Its object model works much like System.Xml: you can select nodes with XPath, change the tree and write it back out as HTML or XML.

This is version 2.0 of an async-first fork of Html Agility Pack. It targets .NET 11 and later. All I/O is async, downloading is built into HtmlDocument, and the public API has nullable annotations. If you're coming from HAP 1.x, read Migrating from 1.x.

Getting started

You need the .NET 11 SDK. Install the Async.HtmlAgilityPack package, or reference the library project, and add using HtmlAgilityPack;.

dotnet add package Async.HtmlAgilityPack

The package ID is different from upstream's HtmlAgilityPack, but the namespaces and the assembly name are the same, so don't reference both in one project.

using HtmlAgilityPack;

var doc = new HtmlDocument();
doc.LoadHtml("""
    <html>
      <body>
        <h1>Products</h1>
        <ul id="list">
          <li class="item" data-price="4.50">Tea
          <li class="item sale" data-price="3.00">Coffee
        </ul>
      </body>
    </html>
    """);

// XPath
string? heading = doc.DocumentNode.SelectSingleNode("//h1")?.InnerText;   // "Products"

// LINQ: the unclosed <li> tags are still separate elements
foreach (HtmlNode li in doc.DocumentNode.Descendants("li"))
{
    decimal price = li.GetAttributeValue("data-price", 0m);
    Console.WriteLine($"{li.InnerText.Trim()}: {price}");
}

The two main types:

  • HtmlDocument loads and saves HTML and holds the parser options. Its DocumentNode is the root of the tree.
  • HtmlNode is every node in the tree: elements, text (HtmlTextNode), comments (HtmlCommentNode) and the document node. Check NodeType to tell them apart.

Loading HTML

Every Load… method replaces the document's current content. Loading from a string is synchronous. Loading from files, streams, readers and the web is asynchronous and takes an optional CancellationToken.

From a string

var doc = new HtmlDocument();
doc.LoadHtml("<p>Hello <b>world</b></p>");

From a file

var doc = new HtmlDocument();
await doc.LoadAsync("page.html");                         // encoding from the BOM, else UTF-8
await doc.LoadAsync("page.html", Encoding.Latin1);        // a specific encoding
await doc.DetectEncodingAndLoadAsync("page.html");        // reads <meta charset> first, then loads

From a stream or TextReader

await using var stream = File.OpenRead("page.html");
await doc.LoadAsync(stream, cancellationToken);

using var reader = new StringReader(html);
await doc.LoadAsync(reader);

The stream overloads leave the stream open. Optional parameters let you set the encoding, turn BOM detection on or off, and set the buffer size.

From the web

LoadHtmlAsync(Uri, …) downloads a page with HttpClient and parses it. It replaces HtmlWeb from 1.x.

var doc = new HtmlDocument();
await doc.LoadHtmlAsync(new Uri("https://example.com/"));

To set headers, timeouts, proxies, cookies, decompression or redirects, configure your own HttpClient and pass it in. The library never disposes a client you pass.

using var http = new HttpClient { Timeout = TimeSpan.FromSeconds(10) };
http.DefaultRequestHeaders.UserAgent.ParseAdd("MyCrawler/1.0");

await doc.LoadHtmlAsync(new Uri("https://example.com/"), http, cancellationToken);

If you need the status code, final URL or response headers, make the request yourself and pass the body to LoadHtml:

using var response = await http.GetAsync(uri);
string html = await response.Content.ReadAsStringAsync();
doc.LoadHtml(html);
Console.WriteLine($"{(int)response.StatusCode} {response.RequestMessage?.RequestUri}");

Parsing a fragment

HtmlNode.CreateNode parses a snippet and returns its first node. The node isn't attached to any document tree yet.

HtmlNode link = HtmlNode.CreateNode("<a href='/about'>About</a>");

Encoding

A document tracks three encodings:

PropertyMeaning
StreamEncodingThe encoding used to read the stream or file. It's null after LoadHtml(string).
DeclaredEncodingThe encoding the markup declares with <meta charset> or <meta http-equiv="content-type">.
EncodingThe encoding used for output: the declared encoding if there is one, otherwise the stream encoding, otherwise OptionDefaultStreamEncoding.

To work out a file's encoding before loading it, use these:

Encoding? fromBom  = await doc.DetectEncodingAsync(stream);                   // BOM only
Encoding? fromMeta = await doc.DetectEncodingAsync(stream, checkHtml: true);  // BOM, then <meta>
Encoding? inMarkup = doc.DetectEncodingHtml(htmlString);                      // <meta> in a string

When OptionReadEncoding is true (the default) and the stream encoding differs from the declared one, the parser records a CharsetMismatch parse error.

For a web page that only declares its charset in markup, download it as bytes, call DetectEncodingAsync(stream, checkHtml: true), rewind the stream, and load it with that encoding. Or pass the encoding directly: LoadHtmlAsync(uri, Encoding.Latin1).

Selecting nodes

XPath

HtmlNode? title = doc.DocumentNode.SelectSingleNode("//head/title");
HtmlNodeCollection? links = doc.DocumentNode.SelectNodes("//a[@href]");

foreach (HtmlNode a in links ?? Enumerable.Empty<HtmlNode>())
    Console.WriteLine(a.GetAttributeValue("href", ""));

SelectNodes returns null when nothing matches, not an empty collection. Handle the null, or set OptionEmptyCollection = true before loading.

XPath runs against the parsed tree, so element and attribute names are lowercase: use //div, not //DIV. Expressions are relative to the node you call them on. Start with .// to search only below the current node, since // always searches the whole document.

HtmlNode list = doc.GetElementbyId("list")!;
var onlyInList = list.SelectNodes(".//li[contains(@class, 'sale')]");

For an expression you run many times, compile it once and pass the XPathExpression:

var expr = XPathExpression.Compile("//td[@class='price']");
var cells = doc.DocumentNode.SelectNodes(expr);

Every node has an XPath property that gives its absolute path, such as /html[1]/body[1]/ul[1]/li[2].

By ID

HtmlNode? list = doc.GetElementbyId("list");   // needs OptionUseIdAttribute (on by default)

LINQ

Descendants, Elements and Ancestors return IEnumerable<HtmlNode>, so you can use LINQ on them:

var saleItems = doc.DocumentNode
    .Descendants("li")
    .Where(li => li.HasClass("sale"))
    .Select(li => li.InnerText.Trim())
    .ToList();

To get readable text, decode the entities:

string text = HtmlEntity.DeEntitize(node.InnerText);   // "Fish & chips"

Text and comment nodes have their own types. HtmlTextNode.Text and HtmlCommentNode.Comment give you the raw content.

Nodes and attributes also record where they came from in the source: Line, LinePosition and StreamPosition, plus InnerStartIndex/InnerLength and OuterStartIndex/OuterLength for nodes. Use them to point back into the original text.

Attributes & classes

Reading

string href   = a.GetAttributeValue("href", "");          // string with default
int    width  = img.GetAttributeValue("width", 0);         // int: default if missing or not a number
bool   active = el.GetAttributeValue("data-active", false);   // "true" / "false"
decimal price = li.GetAttributeValue("data-price", 0m);    // any type with a TypeConverter

// your own parser
DateOnly date = el.GetAttributeValue("data-date", DateOnly.MinValue, DateOnly.TryParse);

HtmlAttribute? att = el.Attributes["class"];               // names aren't case-sensitive
bool has = el.Attributes.Contains("disabled");            // boolean attributes: test presence

GetDataAttribute("price") returns the data-price attribute, and GetDataAttributes() returns all data-* attributes. An attribute's Value is raw. Use DeEntitizeValue to get it with entities decoded.

Writing

a.SetAttributeValue("href", "https://example.com/");  // adds or replaces
a.Attributes.Add("rel", "noopener");                  // always appends
a.Attributes.Remove("target");
a.Attributes["title"]?.Remove();

Attributes you add are written with double quotes. Parsed attributes keep their original quote style unless you change HtmlAttribute.QuoteType or set GlobalAttributeValueQuote on the document.

CSS classes

el.AddClass("active");
el.RemoveClass("hidden");
el.ReplaceClass("btn-primary", "btn-secondary");   // (new, old)
bool on = el.HasClass("active");
IEnumerable<string> all = el.GetClasses();

The overloads with a bool throwError parameter throw instead of doing nothing: AddClass throws if the class is already there, and RemoveClass and ReplaceClass throw if the node has no class attribute.

Manipulating the DOM

Creating nodes

HtmlNode div   = doc.CreateElement("div");
HtmlNode text  = doc.CreateTextNode("Hello &amp; welcome");   // the text is raw HTML: escape it yourself
HtmlNode note  = doc.CreateComment("generated");                 // becomes <!--generated-->
HtmlNode frag  = HtmlNode.CreateNode("<span class='x'>y</span>");

div.InnerHtml = "<b>Bold</b> text";   // parses and replaces the children

Use HtmlDocument.HtmlEncode or HtmlEntity.Entitize to escape text before putting it into CreateTextNode or InnerHtml.

Adding and moving

parent.AppendChild(child);
parent.PrependChild(child);
parent.InsertBefore(newNode, existingChild);   // existingChild must be a child of parent
parent.InsertAfter(newNode, existingChild);
parent.AppendChildren(nodes);                  // appends each node in the collection

AppendChildren and PrependChildren don't detach the nodes from their current parent. To move nodes, call Remove() on each one first, or append clones.

Removing and replacing

node.Remove();                         // detach this node from its parent
parent.RemoveChild(child);             // remove the child and everything below it
parent.RemoveChild(child, keepGrandChildren: true);   // unwrap: keep the child's children in place
parent.ReplaceChild(newChild, oldChild);
node.RemoveAllChildren();              // remove children, keep attributes
node.RemoveAll();                      // remove children and attributes

// Strip every script and style
foreach (var n in doc.DocumentNode.Descendants().Where(n => n.Name is "script" or "style").ToList())
    n.Remove();

Call .ToList() before you change the tree while looping over Descendants(), ChildNodes or SelectNodes. Otherwise the loop stops or skips nodes.

Cloning

HtmlNode deep    = node.Clone();                 // node and everything below it
HtmlNode shallow = node.CloneNode(deep: false);  // node and attributes only
HtmlNode renamed = node.CloneNode("section");    // deep copy with a new name
target.CopyFrom(source);                         // copy attributes and children into an existing node

Saving & writing

await doc.SaveAsync("out.html");                    // in doc.Encoding
await doc.SaveAsync("out.html", Encoding.UTF8);
await doc.SaveAsync(stream);                        // leaves the stream open
await doc.SaveAsync(textWriter);

string html = doc.DocumentNode.OuterHtml;           // in memory: synchronous
string inner = node.WriteContentTo();               // same as InnerHtml
string outer = node.WriteTo();                      // same as OuterHtml

To write a single node to a writer, use WriteToAsync or WriteContentToAsync:

await using var writer = new StringWriter();
await node.WriteToAsync(writer);

XML output

Set OptionOutputAsXml = true to write well-formed XML: empty elements are closed, attributes are quoted, and names are made XML-safe with HtmlDocument.GetXmlName. You can also save straight to an XmlWriter:

var settings = new XmlWriterSettings { Indent = true };
await using var xw = XmlWriter.Create("out.xml", settings);
await doc.SaveAsync(xw);

Entities

HtmlEntity converts between characters and HTML entities.

HtmlEntity.DeEntitize("caf&eacute; &amp; cr&#232;me");    // "café & crème"
HtmlEntity.Entitize("café © 2026");                       // "caf&eacute; &copy; 2026"
HtmlEntity.Entitize("a < b", useNames: true, entitizeQuotAmpAndLtGt: true);  // "a &lt; b"

HtmlNode copy = HtmlEntity.Entitize(node);   // entitized clone of a node; the original is unchanged

EntityName and EntityValue are the lookup tables. Set HtmlEntity.UseWebUtility = true to make Entitize encode with WebUtility.HtmlEncode instead.

Parse errors

The parser never throws on bad markup. It fixes the problem and records it in ParseErrors:

var doc = new HtmlDocument { OptionExtractErrorSourceText = true };
doc.LoadHtml("<div><p>text</div></span>");

foreach (HtmlParseError e in doc.ParseErrors)
    Console.WriteLine($"{e.Line}:{e.LinePosition} {e.Code} {e.Reason} [{e.SourceText}]");
HtmlParseErrorCodeMeaning

TagNotOpenedAn end tag had no matching start tag.
CharsetMismatchThe declared charset differs from the stream encoding.
EndTagNotRequiredAn end tag was given for an element that doesn't need one, such as </br>.
EndTagInvalidHereAn end tag isn't allowed at this position.

Mapping to objects

GetEncapsulatedData<T>() fills a class from XPath expressions declared with attributes from HtmlAgilityPack.Attributes.

using HtmlAgilityPack;
using HtmlAgilityPack.Attributes;

[HasXPath]
public class Article
{
    [XPath("//h1")]
    public string Title { get; set; } = "";

    [XPath("//a[@class='author']", "href")]          // attribute value
    public string AuthorUrl { get; set; } = "";

    [XPath("//div[@class='body']", ReturnType.InnerHtml)]
    public string BodyHtml { get; set; } = "";

    [XPath("//ul[@class='tags']/li")]                 // every match
    public List<string> Tags { get; set; } = [];

    [XPath("//span[@class='rating']")]
    [SkipNodeNotFound]                                // leave the default if missing
    public string? Rating { get; set; }
}

Article article = doc.DocumentNode.GetEncapsulatedData<Article>();
  • [HasXPath] marks a class for mapping. Without it, GetEncapsulatedData throws MissingXPathException.
  • [XPath(xpath)] maps a property to the InnerText of the first match. [XPath(xpath, ReturnType)] picks InnerText, InnerHtml or OuterHtml. [XPath(xpath, attributeName)] reads an attribute instead.
  • Properties whose type is IEnumerable<T> or List<T> get every match.
  • A property whose type is another [HasXPath] class is mapped recursively, starting from the matched node.
  • Values are converted to the property's type.
  • [SkipNodeNotFound]: without it, a missing node throws NodeNotFoundException, and a missing attribute throws NodeAttributeNotFoundException.

The other overloads, GetEncapsulatedData<T>(HtmlDocument) and GetEncapsulatedData(Type, HtmlDocument), map from a given document, or from a type known only at run time.

XPathNavigator & XSLT

HtmlDocument and HtmlNode implement IXPathNavigable. CreateNavigator() returns an HtmlNodeNavigator, an XPathNavigator over the HTML tree. You can use it with XPathNavigator APIs and with XslCompiledTransform:

using System.Xml.Xsl;

var xslt = new XslCompiledTransform();
xslt.Load("transform.xslt");

using var output = new StringWriter();
xslt.Transform(doc.CreateNavigator(), null, output);

You can also create a navigator directly from a file, stream or reader. Use the synchronous constructors or the async factories:

HtmlNodeNavigator nav = await HtmlNodeNavigator.CreateAsync("page.html");
string? title = nav.SelectSingleNode("//title")?.Value;
HtmlNode current = nav.CurrentNode;   // back to the HAP node

Namespaces aren't supported. The namespace members always return empty or false.

MixedCodeDocument

MixedCodeDocument splits a template that mixes text with <% … %> server code (ASP, ASP.NET Web Forms and similar) into text and code fragments.

var mixed = new MixedCodeDocument();
mixed.LoadHtml("<p>Hello <%= user.Name %></p>");

foreach (MixedCodeDocumentFragment f in mixed.Fragments)
    Console.WriteLine($"{f.FragmentType}: {f.FragmentText}");

foreach (MixedCodeDocumentCodeFragment c in mixed.CodeFragments)
    Console.WriteLine(c.Code);

string code = mixed.Code;   // the document as code: each text fragment becomes Response.Write TextBlock(n)

It has LoadAsync/SaveAsync overloads for paths, streams and writers, like HtmlDocument. You can change the delimiters with the TokenCodeStart, TokenCodeEnd, TokenDirective and TokenResponseWrite fields.

Code fragments currently include one extra character after %>. See Known issues.

Security & limits

  • HAP isn't a sanitizer. Removing <script> elements doesn't make HTML safe to show: event handler attributes, javascript: URLs, SVG and CSS can all run code. Use an allowlist-based sanitizer for user-supplied HTML.
  • Deeply nested input. Hostile documents can nest thousands of elements. Set OptionMaxNestedChildNodes (for example, 500) to throw while parsing instead of building a huge tree. HtmlDocument.MaxDepthLevel limits recursion in some tree operations.
  • Large input. The whole document is held in memory. Check Content-Length or limit how much you read before you load untrusted responses. Use OptionStopperNodeName if you only need the start of a page, such as the <head>.
  • Downloads. LoadHtmlAsync follows the redirect and TLS settings of the HttpClient you pass. When the URL comes from users, use a client with your own limits (timeout, redirect count, response size), and block internal addresses if SSRF is a concern.
  • XSLT. If you transform documents with XslCompiledTransform, load stylesheets you trust and keep XsltSettings.Default, which has scripts and document() turned off.

Migrating from 1.x

Version 2.0 isn't a drop-in replacement. The main changes:

HtmlWeb is gone

Synchronous I/O is gone

These are unchanged: LoadHtml(string), WriteTo(), WriteContentTo(), OuterHtml, XPath queries and the HtmlNodeNavigator constructors. HtmlNodeNavigator.CreateAsync is new.

Other changes

  • Namespaces: the mapping attributes are now in HtmlAgilityPack.Attributes, and the mapping exceptions are in HtmlAgilityPack.Exceptions.
  • Nullable annotations: methods like SelectSingleNode, SelectNodes and GetElementbyId are declared as returning nullable types, so you'll see warnings where code assumed a result.
  • Removed: HtmlCmdLine, HtmlConsoleListener and the trace helpers. Crc32 is now internal.
  • Download encoding: see From the web. The page's <meta charset> is no longer used automatically.
